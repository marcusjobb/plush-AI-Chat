# Demo-dokument

Tre dikter som är public domain, för att prova dokumentfunktionen:

- `det_eviga.md`: Esaias Tegnér (1810)
- `forruttnelsen.md`: Erik Johan Stagnelius (1818)
- `the raven.md`: Edgar Allan Poe (1845)

Ladda upp dem med knappen **Ladda upp** i webben, eller från terminalen:

```bash
.venv/bin/python upload.py demo/det_eviga.md
```
