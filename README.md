# plush-AI-Chat

Två små chattar mot en OpenAI-kompatibel endpoint (1min.AI), byggda steg för steg.

- `chat/`: en enkel konsolchatt med historik och `/compact`.
- `multichat/`: en webbchatt med flera assistenter, sessioner, dokumentuppladdning och verktyg.

## Kom igång

Varje mapp har sin egen README med instruktioner. Skapa `.env` från `.env.example` och fyll i din egen API-nyckel. Nycklar och personliga filer committas aldrig.
